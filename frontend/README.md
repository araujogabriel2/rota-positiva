# Frontend — Rota Positiva

Interface da nova arquitetura do Rota Positiva, construída com React, TypeScript, Vite e Bootstrap.

## Execução local

```powershell
Set-Location .\frontend
npm.cmd install
npm.cmd run dev
```

O Vite informará o endereço local, normalmente `http://localhost:5173`.

## Testes e build

```powershell
npm.cmd run test:run
npm.cmd run build
```
